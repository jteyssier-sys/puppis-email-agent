# 🐾 Puppis Email Agent v3

Agente inteligente de asuntos de email para campañas de Puppis.

## 🚀 Acceso rápido

**[Abrir agente →](https://jteyssier-sys.github.io/puppis-email-agent/)**

## ✨ Características

- 14 tipos de campañas precargadas
- Personalización dinámica con datos de cliente
- Benchmarks de OR y CTR en tiempo real
- Generación de fórmulas Liquid
- Soporte para Argentina y Colombia

## 📝 Uso

1. Selecciona país y tipo de mascota
2. Elige tipo de campaña
3. Ingresa beneficio principal
4. Configura campos dinámicos
5. **Generar asuntos** 🐾

## 🛠️ Stack

- HTML5 + CSS3
- Vanilla JavaScript (sin dependencias)
- Responsive design
